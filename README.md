# AgriCore Command Center

Prairie Crest Agricultural Cooperative farm operations app: equipment, field jobs, service reports, and operational analytics.

Local-first stack: **React (Vite) + MUI**, **FastAPI**, **PostgreSQL**, **AWS S3** for report files.

## Prerequisites

- Python 3.10+
- Node.js 20+ and npm
- Docker Desktop (local PostgreSQL)
- AWS IAM keys and a **private** S3 bucket (needed starting Slice 4)

## Quick start

```bash
chmod +x bin/setup.sh bin/seed.sh
./bin/setup.sh
```

`setup.sh` creates `backend/.venv`, installs Python and npm packages, starts Postgres via Docker Compose, and writes local `.env` files (including a generated `JWT_SECRET_KEY`).

### Run the API

```bash
cd backend
source .venv/bin/activate
uvicorn app.main:app --reload --app-dir .
```

Health check: [http://localhost:8000/health](http://localhost:8000/health)  
OpenAPI: [http://localhost:8000/docs](http://localhost:8000/docs)

### Run the UI

```bash
cd frontend
npm run dev
```

UI: [http://localhost:5173](http://localhost:5173)

### Seed data

```bash
./bin/seed.sh
```

Seeding lands in Slice 8. Until then the script exits after a short notice.

## Environment variables

Copy from examples (`backend/.env.example`, `frontend/.env.example`). `bin/setup.sh` does this for you.

### Backend (`backend/.env`)

| Variable | Purpose |
| --- | --- |
| `DATABASE_URL` | SQLAlchemy URL for local Postgres (`agricore` / `agricore` / `agricore` on port 5432) |
| `JWT_SECRET_KEY` | Generated by setup; do not commit |
| `JWT_ALGORITHM` | `HS256` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Default `480` |
| `CORS_ORIGINS` | Comma-separated origins; default `http://localhost:5173` |
| `AWS_ACCESS_KEY_ID` | IAM user (Slice 4+) |
| `AWS_SECRET_ACCESS_KEY` | IAM secret (Slice 4+) |
| `AWS_REGION` | e.g. `us-east-1` |
| `AWS_S3_BUCKET` | Private bucket name |

IAM needs `s3:PutObject`, `s3:GetObject`, and `s3:DeleteObject` on the bucket. Keep the bucket private; the API will issue presigned download URLs.

### Frontend (`frontend/.env`)

| Variable | Purpose |
| --- | --- |
| `VITE_API_BASE_URL` | REST prefix, default `http://localhost:8000/api/v1` |
| `VITE_API_HEALTH_URL` | Scaffold health probe, default `http://localhost:8000/health` |
