# AgriCore Command Center

Prairie Crest Agricultural Cooperative farm operations app: equipment, field jobs, service reports, and operational analytics.

Local-first stack: **React (Vite) + MUI**, **FastAPI**, **PostgreSQL**, **AWS S3** for report files.

## Prerequisites

- Python 3.10+
- Node.js 20+ and npm
- Docker Desktop (local PostgreSQL)
- AWS IAM keys and a **private** S3 bucket (needed starting Slice 4)

## Quick start

```bash
chmod +x bin/setup.sh bin/seed.sh
./bin/setup.sh
```

`setup.sh` creates `backend/.venv`, installs Python and npm packages, starts Postgres via Docker Compose, and writes local `.env` files (including a generated `JWT_SECRET_KEY`).

### Run the API

```bash
cd backend
source .venv/bin/activate
uvicorn app.main:app --reload --app-dir .
```

Health check: [http://localhost:8000/health](http://localhost:8000/health)  
OpenAPI: [http://localhost:8000/docs](http://localhost:8000/docs)

### Run the UI

```bash
cd frontend
npm run dev
```

UI: [http://localhost:5173](http://localhost:5173)

### Migrate and bootstrap admin

```bash
docker compose up -d postgres
./bin/seed.sh
```

`seed.sh` runs `alembic upgrade head`. Full Prairie Crest mock data is Slice 8. Until then, start the API once — it creates a bootstrap admin if none exists:

- Email: `admin@agricore.local`
- Password: `ChangeMeAdmin!` (override with `BOOTSTRAP_ADMIN_PASSWORD` in `backend/.env`)

## Environment variables

Copy from examples (`backend/.env.example`, `frontend/.env.example`). `bin/setup.sh` does this for you.

### Backend (`backend/.env`)

| Variable | Purpose |
| --- | --- |
| `DATABASE_URL` | SQLAlchemy URL for Docker Postgres (`agricore` / `agricore` / `agricore` on **port 5433** — host 5432 is often already taken) |
| `JWT_SECRET_KEY` | Generated by setup; do not commit |
| `JWT_ALGORITHM` | `HS256` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Default `480` |
| `CORS_ORIGINS` | Comma-separated origins; default `http://localhost:5173` |
| `AWS_ACCESS_KEY_ID` | IAM user (Slice 4+) |
| `AWS_SECRET_ACCESS_KEY` | IAM secret (Slice 4+) |
| `AWS_REGION` | e.g. `us-east-1` |
| `AWS_S3_BUCKET` | Private bucket name |
| `BOOTSTRAP_ADMIN_EMAIL` | Default `admin@agricore.local` |
| `BOOTSTRAP_ADMIN_PASSWORD` | Default `ChangeMeAdmin!` |
| `BOOTSTRAP_ADMIN_NAME` | Display name for the first admin |

IAM needs `s3:PutObject`, `s3:GetObject`, and `s3:DeleteObject` on the bucket. Keep the bucket private; the API will issue presigned download URLs.

### Frontend (`frontend/.env`)

| Variable | Purpose |
| --- | --- |
| `VITE_API_BASE_URL` | REST prefix, default `http://localhost:8000/api/v1` |
| `VITE_API_HEALTH_URL` | Scaffold health probe, default `http://localhost:8000/health` |

## API (current)

| Method | Path | Who | Notes |
| --- | --- | --- | --- |
| `GET` | `/health` | public | Liveness |
| `POST` | `/api/v1/auth/login` | public | `{ "email", "password" }` → JWT + user |
| `GET` | `/api/v1/auth/me` | any role | Current user |
| `GET` | `/api/v1/auth/admin-check` | admin | RBAC smoke test |
| `GET/POST` | `/api/v1/farms` | GET admin+auditor; POST admin | List / create |
| `GET/PATCH/DELETE` | `/api/v1/farms/{id}` | GET admin+auditor; write admin | |
| `GET/POST` | `/api/v1/users` | GET admin+auditor; POST admin | Admin creates accounts (no public signup) |
| `GET/PATCH/DELETE` | `/api/v1/users/{id}` | GET admin+auditor; write admin | |
| `GET/POST` | `/api/v1/equipment` | GET all roles (field hand: assigned only); POST admin | |
| `GET/PATCH/DELETE` | `/api/v1/equipment/{id}` | GET scoped; write admin | |
| `GET/POST` | `/api/v1/field-jobs` | GET all roles (field hand: own jobs); POST admin | |
| `GET/PATCH/DELETE` | `/api/v1/field-jobs/{id}` | PATCH: admin any fields; field hand **status only** on own jobs; DELETE admin | |
| `GET` | `/api/v1/audit-logs?q=` | admin+auditor | Search `action`, `entity_type`, `details` |

Writes append an `audit_logs` row (`actor_id`, `action`, `entity_type`, `entity_id`, `details`). Unique email/serial conflicts return `409`.

```bash
TOKEN=$(curl -sS -X POST http://localhost:8000/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"admin@agricore.local","password":"ChangeMeAdmin!"}' \
  | python3 -c 'import json,sys; print(json.load(sys.stdin)["access_token"])')

curl -sS http://localhost:8000/api/v1/auth/me -H "Authorization: Bearer $TOKEN"
```

Analytics and report uploads are later slices.

## Roles

- **Farm Operations Admin** — full CRUD (JWT `role=admin`)
- **Field Hand** — assigned equipment, own job status (`field_hand`); service reports in Slice 4
- **Auditor** — GET-only on farms/users/equipment/jobs plus audit log search (`auditor`)

Dependencies: `get_current_user`, `require_roles(...)` in `backend/app/api/deps.py`.
